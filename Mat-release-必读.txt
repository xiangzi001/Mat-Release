
这是我自己搓的数值线性代数库（也可以套用符号模板）
这个库从2023年开始写，已经写3年了
如果觉得好用，帮忙推广一下，使用时注明出处

这个库可以使用自定义的模板，如分式、根式、float128等等（必须定义相应的基本函数，有些函数可能用不了）
还提供了更多高精度方法，如Jacobi的EVD_H和SVD，GramSchmidt的QR

如果硬件，可以启用AVX512，就在头文件Mat.h的最前面加上#define __AVX512__

如果是控制台，可以添加输入输出（输入时矩阵大小已经给定）
template<typename T>
istream& operator >> (istream& in, MAT<T>& A) {
	for (int i = 0; i < A.rows; ++i) {
		string line;
		getline(in, line);
		if (line.size() == 0) {
			getline(in, line);
		}
		for (int i = 0; i < line.size(); ++i) {
			if (line[i] == ',') line[i] = ' ';
		}

		istringstream iss(line);
		for (int j = 0; j < A.cols; ++j) {
			iss >> A(i, j);
		}
	}
	return in;
}

template<typename T>
ostream& operator << (ostream& out, __BlockMat<T>& A) {
	for (int x = 0; x < A.rows; ++x) {
		for (int y = 0; y < A.cols; ++y) {
			out << A[y][x];
			out << ",";
		}
		out << endl;
	}

	return out;
}

0.0
这是第1个正式发布版

目前在double的前提下，计算小矩阵，所有的函数，速度都比市面上任何数值线性代数库都快。
目前在单线程double的前提下，计算大矩阵，所有优化过大矩阵分块的函数，速度都比市面上任何数值线性代数库都快，如乘法、PLU、Inv、LLT、LDLT、QR、EV_H、EVD_H(CDC)。
测试数据可看Test-2000文件

但现在有这些不足：
1.非对称矩阵特征值（EVD）、奇异值分解（SVD）没做大矩阵分块优化（这些后面大概率不会做，因为这两个的大矩阵精确求解算法几乎不会用到，但可能会做随机SVD等等大矩阵的算法），因此在矩阵较大时会比OpenBlas慢（128~200内我的EVD比OpenBlas快很多，SVD在72内我更快）
2.没做多线程，主要是觉得多线程比较好写，懒得去测试和优化了（OpenBlas的多线程大矩阵提速最大2倍，而且在128阶以下单线程还快不止1倍）（以后我可能会写多线程，但概率不是很大）
3.复数的EVD_H和SVD都没做，后面肯定会做复数的EVD_H（复数的SVD用的太少，也大概率不会做）
4.复数目前没有用SIMD做矩阵乘法，后面肯定会做
5.分块大小是直接定义的，没根据具体硬件情况，后面会改（你也可以在Mat.h修改参数，目前这个是适合普通笔记本的参数）
